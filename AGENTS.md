# Рекомендации по интерфейсу редактора

- Для выбора из небольшого фиксированного набора вариантов предпочитать видимые радиокнопки или группы кнопок выпадающим спискам. Это особенно относится к цветам, группам триггеров, направлениям и другим свойствам объектов.
- Использовать существующие компоненты редактора (например, `colorRadios` для цветовых вариантов). Разным свойствам назначать отдельные имена радиогрупп, чтобы выбор одного свойства не сбрасывал другое.
- Выпадающие списки оставлять для длинных или динамических наборов, где кнопки заметно перегружают интерфейс.

# Иконки и текст в интерфейсе

- Если смысл однозначно передаётся иконкой, предпочитать её видимой текстовой подписи: например, секундомер для времени, череп для смертей, цветной кубик с черепком для персонажа-желейки. Это уменьшает объём перевода.
- Повторно использовать существующие изображения иконок, в том числе значки персонажей из редактора, сохраняя их цвета и стиль.
- Сохранять понятные локализованные подписи для скринридеров (`aria-label`); текст оставлять видимым там, где одной иконки недостаточно для понимания.
