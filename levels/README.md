# Карты Jelly & Bones

Каждый уровень хранится в отдельном JSON в том же формате версии 1, который экспортирует редактор. Чтобы изменить карту, замените её JSON экспортом из редактора, сохранив имя файла.

Доступны пять цветов желе: зелёный (0), синий (1), красный (2), фиолетовый (3), жёлтый «Янтарь» (4). Жёлтый доступен для блоков, спавнов, финишей, шипов и лучей/целей дрона. Массивы `spawns` и `goals` нормализуются до пяти слотов; старые файлы с четырьмя слотами совместимы. Для пятого персонажа одновременно используются NumPad 8/4/5/6; если жёлтый один, доступны обычные WASD и стрелки.

`catalog.js` задаёт список и порядок карт в объекте `catalog`. Это обычный JavaScript: можно использовать комментарии и завершающие запятые. Файл предоставляет `JellyLevelCatalog` браузеру и `module.exports` для Node.js; сами карты остаются JSON.

- `standard`: массив имён JSON-файлов. Их порядок задаёт последовательность кампании; номера в меню вычисляются автоматически. Переставляйте строки, не переименовывая сами файлы.
- `extra`: зарезервированный список дополнительных уровней. Сейчас пуст; отдельный раздел меню для них пока не реализован.

Редактор показывает в списке карт и все остальные JSON из этой папки (группа «Другие карты»). Список строится автоматически: сервер разработки отдаёт его по адресу `levels/index.json`, а сборка для itch.io генерирует этот файл и кладёт в архив все читаемые карты. Добавлять такие файлы в каталог не нужно.

Для добавления стандартного уровня положите его JSON в эту папку и добавьте имя файла в любое место `standard`. Число уровней и финальный экран определяются по каталогу. Прогресс привязан к именам файлов: уже открытые карты сохраняют доступность после перестановок. Переименование файла считается новой картой. Цифры в начале существующих имён файлов — только часть имени, а не порядок прохождения.

Название хранится **только внутри JSON карты**: `name` — основное название, `names.ru` — необязательный русский перевод. Для других языков можно добавить ключи в `names`. Меню, загрузка и экран победы читают эти поля напрямую; записи в каталоге или `i18n.js` не нужны. Без перевода показывается `name`. Редактор сохраняет переводы при импорте/экспорте.

Файлы загружаются по HTTP через `level-loader.js`; запускайте проект командой `npm.cmd start`.
В редакторе рабочая область расширяется автоматически: X/Z могут быть отрицательными и выходить за прежние 16 клеток. Поле `size` в JSON остаётся техническим; вручную настраивать его не требуется. Вспомогательная сетка показывает запас в три клетки вокруг объектов, а «Вписать» подбирает вид по построенному уровню.

Шипы (`spikes`) поддерживают `cycle` (секунды полного цикла, по умолчанию 5.8), `enabled` (начальное состояние, по умолчанию true) и `plate` (id управляющей кнопки). При `cycle: 0` флажок `enabled` задаёт постоянное состояние. Если задан `plate`, кнопка управляет напрямую: нажата — выдвинуты, отпущена — скрыты; цикл и флажок игнорируются. `offset` задаёт сдвиг циклической анимации в секундах.


Решётки (`grates`) — самостоятельные секции из тёмного металла без каменных опор: `{ "x": 3, "y": 1, "z": 3, "axis": "x" }`. Вертикальная секция занимает высоту от `y - 1` до `y`, как каменный куб, но имеет толщину 0.2 клетки с учётом креплений. `axis` задаёт направление секции вдоль X или Z (по умолчанию X). `plane: "horizontal"` кладёт секцию плашмя; без этого поля она стоит вертикально. `offset` равен −0.5, 0 или 0.5 и сдвигает секцию от центра к одной из двух границ клетки по нормали к её плоскости (для горизонтальной секции — вниз или вверх). На разных гранях одной клетки можно размещать несколько секций. Крайние позиции утоплены внутрь на половину толщины решётки: наружная поверхность совпадает с границей клетки, а прутья, поперечины и заклёпки целиком остаются внутри неё. Секции соседних клеток независимы. Решётки пропускают желе всех цветов, лучи дронов и стрелы скелетов, но задерживают ящики и бочки. В редакторе инструмент находится в группе «Блоки»; направление меняется кнопками кисти или в свойствах секции. Решётку можно ставить над отдельным полом, соединять в ряды и наращивать по высоте.

Дроны (`drones`) поддерживают независимое слежение по осям: `"follow": ["x", "z"]`. По выбранным осям X/Z дрон повторяет координаты живой цели; по Y повторяет высоту основания игрока, сохраняя заданную высоту полёта `hover` и зазор над полом. Остальные координаты берутся из исходного положения дрона. Если `follow` не задан или пуст, дрон неподвижен. Цель задаётся существующим свойством `target`; режим ближайшей желейки сравнивает расстояния от исходного положения дрона. При отсутствии живой цели дрон возвращается в исходное положение. Слежение вычисляется из координат игроков и корректно восстанавливается при отмене хода и перезапуске. После телепортации цели дрон не переносится мгновенно, а летит к новой разрешённой позиции со скоростью 4 клетки в секунду.
