# Карты Jelly & Bones

Каждый уровень хранится в отдельном JSON в том же формате версии 1, который экспортирует редактор. Чтобы изменить карту, замените её JSON экспортом из редактора, сохранив имя файла.

`catalog.json` задаёт список и порядок карт:

- `standard`: массив имён JSON-файлов. Их порядок задаёт последовательность кампании; номера в меню вычисляются автоматически. Переставляйте строки, не переименовывая сами файлы.
- `defaultLevel`: имя файла для исходного просмотра и кнопки «Оригинал» в редакторе. Оно не зависит от позиции карты в списке.
- `extra`: зарезервированный список дополнительных уровней. Сейчас пуст; отдельный раздел меню для них пока не реализован.

Для добавления стандартного уровня положите его JSON в эту папку и добавьте имя файла в любое место `standard`. Число уровней и финальный экран определяются по каталогу. Прогресс привязан к именам файлов: уже открытые карты сохраняют доступность после перестановок. Переименование файла считается новой картой. Цифры в начале существующих имён файлов — только часть имени, а не порядок прохождения.

Название хранится **только внутри JSON карты**: `name` — основное название, `names.ru` — необязательный русский перевод. Для других языков можно добавить ключи в `names`. Меню, загрузка и экран победы читают эти поля напрямую; записи в каталоге или `i18n.js` не нужны. Без перевода показывается `name`. Редактор сохраняет переводы при импорте/экспорте.

Файлы загружаются по HTTP через `level-loader.js`; запускайте проект командой `npm.cmd start`.
