# Карты Jelly & Bones

Каждый уровень хранится в отдельном JSON в том же формате версии 1, который экспортирует редактор. Чтобы изменить карту, замените её JSON экспортом из редактора, сохранив имя файла.

`catalog.json` задаёт список и порядок карт:

- `standard`: стандартные уровни кампании. `id` — последовательные номера начиная с 1, `name` — название для меню, `file` — имя JSON в этой папке.
- `defaultLevel`: карта для исходного просмотра и кнопки «Оригинал» в редакторе. Сейчас это уровень 5.
- `extra`: зарезервированный список дополнительных уровней. Сейчас пуст; отдельный раздел меню для них пока не реализован.

Для добавления стандартного уровня положите его JSON в эту папку и добавьте следующую запись в `standard`. Число уровней в прогрессе и финальный экран определяются по каталогу. Существующие файлы и номера лучше сохранять: с ними связан прогресс игроков.

Названия существующих карт переводятся через `i18n.js`. Для нового названия можно добавить туда перевод; без него показывается текст из каталога. Название внутри JSON используется на экране загрузки и победы — держите его согласованным с `name` в каталоге.

Файлы загружаются по HTTP через `level-loader.js`; запускайте проект командой `npm.cmd start`.
