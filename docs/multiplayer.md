# Сетевая игра

Состояние на 11 ноября 2026: рабочий прототип. Играть можно между окнами одного браузера без сервера и через ретранслятор (локальный запущен и проверен; в Cloudflare ещё не опубликован).

## Решения

- **Lockstep по вводу.** Каждый компьютер сам считает мир; по сети идёт только ввод. Основа — бит-в-бит воспроизводимая симуляция (см. «Determinism» в `technical-notes.md`).
- **Хост — часы.** Хост ставит последний известный ввод каждого игрока на тик и рассылает всем. Опоздавший ввод не останавливает игру: берётся предыдущий.
- **Смешанный режим.** Компьютер может вести несколько желеек (хотсит). Желейки раздаются по кругу в порядке подключения; выбор в лобби — позже.
- **Камера у каждого своя.** Она не входит в симуляцию и не синхронизируется.
- **Хост решает**: рестарт, отмена хода и выбор уровня — только у хоста, для всех на одном тике. R и Z у гостя — просьба: над его желейкой у всех на 3 секунды появляется облачко с клавишей и действием («R Сначала!», «Z Отменить!»). Ход для отмены начинается на тике, когда кто-то нажал клавишу после того, как все отпустили; поэтому история ходов одинакова у всех. Ползунки мягкости в сети отключены: они меняют мир в обход общего ввода.
- **Вход и возврат в любой момент.** Хост хранит журнал ввода с начала уровня (или последнего рестарта); подключившийся проигрывает его и догоняет. Вернувшийся после разрыва получает ту же желейку.
- **Потеря связи.** Через 0,7 с тишины над желейкой игрока появляется значок, она останавливается, игра продолжается. Что делать, если игрок ушёл совсем (пауза?), — не решено.
- **Общие эффекты идут по тикам.** Пока уровень играется, обломки желе, руны финишей и факелы шагают вместе с симуляцией и берут случайность из номера тика, поэтому совпадают на всех экранах и у подключившегося позже. Вне игры (сборка уровня, победа, меню одиночной игры) они по-прежнему идут по кадрам. Пот, пыль и вспышки зависят от своей камеры и не сверяются.
- **Порядок и потери.** Пакеты хоста нумерованы: обогнавшие ждут пропущенный, через 0,25 с гость просит повтор (хост помнит около 15 секунд), иначе перезагружает уровень. Ввод гостя тоже нумерован, устаревший отбрасывается.
- **Транспорт заменяемый.** Сессии нужен объект с `send(message, to)` и `onmessage(message, from)`. Есть два: `BroadcastChannel` между окнами одного браузера и WebSocket через ретранслятор. Дальше — WebRTC напрямую с ретранслятором как сигнальным сервером и запасным путём, затем Steam.
- **Порядок выпуска:** itch.io раньше Steam.

## Как попробовать

`npm start`, затем два **отдельных окна** одного браузера рядом (скрытая вкладка не рисует кадры и замирает):

- хост: `http://localhost:3000/?level=1&play=1&room=test&host=1`
- гость: `http://localhost:3000/?room=test&play=1`

Гость сам перейдёт на уровень хоста. `&ping=120` в адресе гостя добавляет искусственную задержку (мс, туда-обратно); её же меняет ползунок «Пинг сети (тест)» в панели разработчика (клавиша `` ` ``). Окно гостя нужно открывать заново по адресу, а не дублировать вкладку: дубликат получит тот же идентификатор.

## Ретранслятор

`relay/` — Cloudflare Worker: одна комната — один Durable Object, который пересылает сообщения между хостом и гостями. Состояния игры он не хранит и сообщений не разбирает. В комнате до 8 подключений.

- Локально: `npm run relay:dev` (порт 8787, аккаунт не нужен), затем к адресам игры добавить `&relay=dev`.
- Публикация: один раз `npx wrangler login` (откроет браузер), затем `npm run relay:deploy`. Команда напечатает адрес вида `https://jelly-bones-relay.<имя>.workers.dev`; его с `wss://` вместо `https://` нужно вписать в `src/net/config.js` (`relayUrl`). После этого любая ссылка с `?room=…` идёт через ретранслятор; `&relay=local` возвращает режим «окна одного браузера».
- Второй компьютер не может открыть игру по `http://<адрес в локальной сети>:3000`: WebGPU работает только на `localhost` и по HTTPS. Для локальной сети используйте `npm run start:https` и [настройте доверие сертификату](development.md#проверка-с-iphone-по-локальной-сети) на каждом устройстве. Также подойдут опубликованная сборка (GitHub Pages, itch) либо свой `npm start` на каждом компьютере.
- Лимиты бесплатного тарифа Cloudflare не проверялись. Хост шлёт около 60 сообщений в секунду; если упрёмся, первым делом вдвое уменьшить частоту (пакет раз в два кадра).

## Файлы

- `src/net/lockstep.js` — сессия: роли, тики, журнал, команды, сверка хешей, темп клиента.
- `src/net/local-transport.js` — транспорт между окнами одного браузера.
- `src/net/ws-transport.js` — транспорт через ретранслятор, с переподключением.
- `src/net/delay.js` — искусственная задержка поверх любого транспорта.
- `src/net/config.js` — адрес опубликованного ретранслятора.
- `src/net/index.js` — включение по адресу страницы (`room`, `host`, `ping`, `relay`).
- `relay/src/index.js`, `relay/wrangler.toml` — ретранслятор.
- `src/net/memory-transport.js` — сеть в памяти для тестов.
- `src/game.js` — `simulateNet`, `applyNetCommand`, `netRosterChanged`, `updateNetStatus`.
- Тесты: `tests/lockstep.test.js` (в `npm test`), `npm run test:net:browser` (с `RELAY=dev` — через локальный ретранслятор), `npm run profile:net-replay`.

## Известные ограничения

- Гость чувствует задержку, равную пингу: его ввод идёт к хосту и обратно. У хоста задержки нет. По ощущениям автора: 50 мс почти незаметно, 100 мс уже чувствуется, при 200 мс играть сложнее. Лечится предсказанием своей желейки с откатом; шаг мира ≈0,4 мс, так что это реально. Это следующая по важности задача после настоящего транспорта.
- Вход посреди уровня проигрывает журнал в 25–30 раз быстрее реального времени (замер `npm run profile:net-replay` на Apple silicon: 21 с игры за 0,7 с). Минута отставания — около 2 секунд, десять минут — около 20. Мгновенный вход потребует передачи полного снимка мира.
- Рестарт сбрасывает мир на месте (`reset()`), а подключившийся после рестарта создаёт уровень заново. Эквивалентность проверена тестом на первом уровне, не на всех.
- При рассинхроне игра только сообщает о нём; восстановления нет.
- Уровень из редактора (`level=editor`) в сети не поддерживается.
- Лобби, код комнаты в меню и выбор желеек не сделаны: комната задаётся адресом.
